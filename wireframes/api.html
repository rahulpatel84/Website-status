Public API

Free, no key required for read endpoints. JSON everywhere. CORS-enabled.

Base URL
https://status.watch/api

Endpoints

Existing routes from the app, documented for public use.

GET/api/check-status?url=

Live HTTP HEAD check against a URL. 10s timeout. Returns { up, statusCode, responseTimeMs }.

GET/api/outage-stats?company=&hours=24

Hourly aggregated report counts by issue type for the given service.

GET/api/outage-locations?company=&hours=6

Geo-tagged reports for the heatmap. Returns lat/lng + city.

GET/api/outage-city-reports?company=&city=

City-level breakdown of reports with issue-type tags.

POST/api/report-outage

Submit an outage report. Rate limited to 3/min per hashed IP. Body: { company_slug, issue_type }.

SSE/api/events?company=

Server-sent events stream. Emits report.new, comment.new, status.changed.

Example

curl -s https://status.watch/api/outage-stats?company=instagram&hours=24

Rate limits & terms

  • 60 requests/min per IP for read endpoints.
  • 3 POSTs/min per hashed IP for reporting.
  • Attribution appreciated but not required. Please don't scrape aggressively.
