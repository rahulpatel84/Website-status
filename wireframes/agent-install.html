Install the agent in your project

One line to add. Automatic diagnostic waterfall for every check. Works with Node, Python, curl, and browser JS.

Node.js Python curl / heartbeat Browser JS

1 · Install

# npm npm install @statuswatch/agent # or pnpm / bun / yarn pnpm add @statuswatch/agent

2 · Initialize once, at the top of your entry file

// index.ts import { Statuswatch } from "@statuswatch/agent"; const sw = Statuswatch.init({ project: "acme-prod", token: process.env.STATUSWATCH_TOKEN, // project token dependencies: { postgres: () => db.raw("select 1"), stripe: () => fetch("https://api.stripe.com/v1/ping"), redis: () => redis.ping(), }, });

3 · Add a health route (recommended)

// Express app.get("/health", sw.expressHealth()); // Or manually app.get("/health", async (_, res) => { const report = await sw.diagnose(); res.status(report.ok ? 200 : 503).json(report); });

Point your URL monitor at /health. When it fails, the response body tells us which layer broke (DNS/TCP/TLS/HTTP/DB/upstream).

4 · Wrap your cron / worker jobs

// A dead-man's switch — we alert if this doesn't check-in on schedule. import { Statuswatch } from "@statuswatch/agent"; const job = Statuswatch.job("nightly-backup"); await job.run(async () => { await backupToS3(); }); // job.run() automatically calls .start() before + .complete()/.fail() after.

5 · Or use the raw curl heartbeat (no SDK required)

## end of your cron 0 3 * * * /usr/bin/backup.sh && \ curl -fsS -m 10 --retry 3 "https://api.statuswatch.io/hb/hb_9e3f...token"

Diagnostic waterfall

On failure the agent probes each layer and stops at the first broken one.

  1. DNS resolve
  2. TCP connect
  3. TLS handshake
  4. HTTP HEAD (200 OK?)
  5. Response body assertion
  6. Registered dependencies (DB, Redis, upstream)
  7. Local runtime (event loop, memory)
